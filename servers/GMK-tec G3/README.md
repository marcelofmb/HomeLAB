# GMKtec N100

## Overview

The GMKtec mini PC with an Intel N100 processor is intended to be the
low-power, always-on machine in my homelab. It will host lightweight
services that I want available without keeping the larger lab machines
running.

## Hardware

-   Device: GMKtec Mini PC
-   Processor: Intel N100
-   RAM / storage: 8GB / 254GB

## Services

  Service            Purpose                      Status
  ------------------ ---------------------------- ----------
  Minecraft server   Host a Minecraft world       Online
  Pi-hole            Network-wide DNS filtering   Online
  Tailscale          Secure remote access         Online

## Notes

The aim is to keep this machine focused on everyday services. More
experimental workloads can run on the ThinkCentre machines so testing
does not unnecessarily affect these services.
