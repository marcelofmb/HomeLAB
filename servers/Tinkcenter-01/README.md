# Lenovo ThinkCentre M700 #2

## Overview

This ThinkCentre runs Ubuntu Server and is used to practise Linux server
administration and container management. It also hosts monitoring and
security-related lab services.

## Hardware

-   Device: Lenovo ThinkCentre M700
-   Operating system: Ubuntu Server
-   CPU / RAM / storage: To be documented
-   Container platform: Docker

## Services and tools

  -----------------------------------------------------------------------
  Service / tool                      Purpose
  ----------------------------------- -----------------------------------
  OWASP Juice Shop                    Intentionally vulnerable web
                                      application for security practice

  Grafana                             Visualise monitoring data

  Loki                                Log aggregation

  Promtail                            Collect and forward logs

  Suricata                            Network threat detection

  RackPeek                            Homelab rack / equipment
                                      visualisation
  -----------------------------------------------------------------------

Service availability and deployment may change as the lab develops.

## Purpose

-   Practise Linux administration.
-   Learn Docker and container networking.
-   Collect and analyse logs.
-   Explore network monitoring and intrusion detection.
-   Run security exercises in a controlled environment.
