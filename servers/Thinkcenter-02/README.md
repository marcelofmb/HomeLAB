# Lenovo ThinkCentre M700 #1

## Overview

This ThinkCentre is used for virtualisation and cybersecurity practice.
It provides a place to run virtual machines and experiment without using
the main services machine.

## Hardware

-   Device: Lenovo ThinkCentre M700
-   CPU / RAM / storage: i5 6500T / 8GB / 254GB

## Software

-   Hypervisor: Proxmox VE
-   Virtual machine: Kali Linux

## Purpose

-   Learn virtualisation and VM management.
-   Practise Linux and cybersecurity tools.
-   Build isolated environments for security exercises.
-   Experiment without putting the main homelab services at risk.
